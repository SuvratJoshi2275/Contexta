# Viva guide

**Lexical ambiguity:** one word form can denote multiple meanings. Homonymy concerns unrelated meanings, while polysemy involves related senses. **WSD:** choosing the appropriate sense given context. **Dictionary baseline:** always chooses the fixed default sense, regardless of sentence. **Rule engine:** matches explicit contextual cues; conflicts/zero evidence trigger a transparent fallback. **POS/dependency features:** grammatical category and syntactic relations, planned extensions. **Contextual embeddings:** a transformer assigns token representations conditioned on neighboring words; offset alignment maps character target spans to subword tokens. **Fine-tuning:** updates model parameters using labelled examples, unlike averaging frozen representations. **Code mixing:** English/Hindi tokens within one utterance; COMI-LINGUA provides annotated token-level LID. **Macro-F1:** averages per-class F1 equally; weighted F1 weights by support. **Leakage:** test contexts must never influence rules, thresholds or model fitting. **Demo:** open Translation Lab, compare financial vs river bank, inspect rule evidence, browse 35 words, then inspect corpus audit and annotation queue.
